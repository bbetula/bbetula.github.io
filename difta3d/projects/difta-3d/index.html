The idea

DIFTA-3D replaces the task-specific visual branch of IIFNet3D with depth-consistent evidence from a frozen DINOv3 encoder. The geometric proposal path, RoI grid, and bidirectional fusion blocks remain in place.

Three stages

  1. Project each scene point into calibrated RGB and depth cameras.
  2. Filter samples whose camera-space depth disagrees with the observed depth image.
  3. Aggregate accepted features inside proposal-aligned RoI grids before instance fusion.

Results

On ScanNetV2, the DINOv3 control reaches 76.15 mAP@0.25 and 60.93 mAP@0.50. Conservative VAID reaches 76.59 and 62.16 under the checkpoint-level recipe comparison.

The comparison is reported as a controlled transfer recipe. The external IIFNet3D reference uses a different visual branch and processing protocol.
